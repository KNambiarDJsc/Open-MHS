# Code of Conduct

OpenMHS is a project about getting machines to behave safely around people. The
community around it should be one where people can disagree, ask basic questions and
report mistakes without being treated badly.

This code is written for a small project and is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(CC BY 4.0).

## Expected behaviour

- Be respectful and assume good faith. Criticise code and ideas, not people.
- Welcome newcomers; answer the question that was asked.
- Say what you know and what you do not. In this project that includes safety claims:
  separate what was tested from what is hoped.
- Accept review and corrections gracefully, and give them kindly.

## Unacceptable behaviour

- Harassment, discrimination, threats, or demeaning comments about anyone's identity
- Personal attacks, trolling, or sustained disruption of discussions
- Publishing someone's private information
- Sexualised language or attention
- Pressuring people to weaken safety or security checks
- Other conduct that a reasonable person would consider inappropriate in a professional
  setting

## Scope

This applies in all project spaces (the repository, issues, pull requests, discussions)
and when someone represents the project in public.

## Enforcement

Maintainers may edit or remove comments, lock threads, and block people who break this
code. To report a problem, contact the maintainer privately through the contact details
on their [GitHub profile](https://github.com/KNambiarDJsc), or use a private security
advisory on the repository if the report is sensitive. Reports are handled
confidentially. Maintainers who are involved in an incident do not decide on it.

Consequences are proportionate: a private warning, a public warning, a temporary
block, or a permanent ban.
