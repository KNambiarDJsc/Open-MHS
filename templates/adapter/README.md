# OpenMHS adapter: example lamp

An [OpenMHS](https://github.com/KNambiarDJsc/Open-MHS) adapter, generated by
`openmhs adapter new`. It starts as a working adapter for an example lamp that speaks a
line protocol, with a fake lamp to test against. Make it yours by following the
[adapter author's guide](https://github.com/KNambiarDJsc/Open-MHS/blob/main/docs/adapters/README.md).

| File | What it is |
|---|---|
| `descriptor.json` | What the device is and can do: capabilities, units, ranges, limits, verification |
| `src/lib.rs` | The adapter: reads, writes, actions, and how each failure is classified |
| `src/link.rs` | The connection to the device (a line protocol over TCP) |
| `src/fixture.rs` | A fake lamp with faults on demand, for tests |
| `tests/conformance.rs` | Runs the OpenMHS conformance suite against the fake lamp |
| `examples/serve.rs` | Serves the adapter in a local gateway |

```sh
cargo test                                   # conformance; reports in target/tmp/conformance/
cargo run --example serve -- --home ./home   # a gateway with this adapter
```

A conformance level is not a safety certification. Test against the fake device; connect
real hardware only with the operator's approval and with its own safety systems in place.
