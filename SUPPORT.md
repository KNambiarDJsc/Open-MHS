# Getting help

OpenMHS is a pre-alpha open-source project maintained in spare time. There is no paid
support and no SLA.

| I want to... | Go to |
|---|---|
| Learn how it works | [README](README.md), [documentation](docs/), [specification](spec/README.md) |
| Fix a problem I hit | Search [existing issues](https://github.com/KNambiarDJsc/Open-MHS/issues), then open a bug report with the template |
| Ask a question or share an idea | GitHub Discussions, if enabled; otherwise open an issue with the question template |
| Propose a larger change | An [RFC](docs/rfcs/0000-template.md) |
| Report a vulnerability | [SECURITY.md](SECURITY.md); never a public issue |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

Please say which platform you are on, the output of `openmhs --version`, and whether
you used simulators or real hardware. OpenMHS has not been run against physical
hardware by the project, so hardware reports are especially useful.

OpenMHS is not an emergency-stop or safety product. Do not use it where a malfunction
could injure anyone.
